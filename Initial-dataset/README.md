# Initial Dataset

This folder holds the datasets used across the internship, in the order they enter the pipeline. Each project either consumes one of these files or produces the next one downstream.

## Data lineage

1. **`Dataset for Data Analytics - Sheet1.csv`** — the raw source dataset
   1,200 e-commerce orders, as originally supplied. Unclean: contains missing values, potential outliers, and no derived features.

2. **`cleaned_dataset_project1.csv`** — output of Project 1
   Produced by the Project 1 notebook (EDA & Feature Engineering). Missing values handled, outliers treated (IQR capping), and 5 new features engineered (`PricePerItem`, `UsedCoupon`, `OrderMonth`, `OrderYear`, `CalculatedTotal`). This is the shared, analysis-ready dataset used as input for both Project 2 and Project 3.

3. **`Synthetic-dataset/project2_fraud_dataset.csv`** — synthetic fraud-labeled dataset, built for Project 2
   The original data has no real fraud label, so this dataset adds a synthetic `IsFraud` target for Project 2's fraud-detection pipeline. The label is generated by a documented, reproducible probabilistic mechanism based on transaction-value percentile, unit-price percentile, quantity, cart size, payment type, coupon usage, and referral source. This is explicitly disclosed as an **educational synthetic target**, not a real fraud signal — model performance reflects recovery of that simulated mechanism, not real-world fraud detection.

4. **Amazon reviews dataset** (external, not stored in this repo) — input for Project 4
   Project 4 pulls in a separate, public labeled review dataset via Kaggle (`walimuhammadahmad/amazone-reviews`) using `kagglehub`. It's kept external and separate from the e-commerce data above because no verified shared key exists between the two — it isn't merged in, just used to extend the internship's analysis into unstructured text/sentiment.

5. **`project4_cleaned_reviews.csv`** — output of Project 4
   The Amazon review dataset after Project 4's NLP preprocessing pipeline (lowercase → clean → tokenize → stop-word removal → lemmatization), with sentiment normalized to Positive/Negative. This is the artifact saved at the end of Project 4.

## Summary

    Sheet1 (raw)
      → cleaned_dataset_project1.csv        [Project 1 output → Project 2 & 3 input]
      → project2_fraud_dataset.csv           [synthetic, Project 2 input]

    Amazon reviews (external, Kaggle)
      → project4_cleaned_reviews.csv         [Project 4 output]

The e-commerce lineage (steps 1–3) and the review lineage (steps 4–5) are two separate tracks that are never merged — they represent structured transaction analysis and unstructured customer-feedback analysis respectively.
