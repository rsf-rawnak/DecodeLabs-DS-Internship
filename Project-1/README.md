# Data Science Internship — Project 1

## Advanced EDA & Feature Engineering

This project is part of the DecodeLabs Data Science Internship program.

The objective of this project is to transform a raw e-commerce dataset into a clean and analysis-ready dataset through exploratory data analysis, statistical data cleaning, outlier treatment, and feature engineering.

---

## Project Objectives

The main objectives of this project are:

- Perform Exploratory Data Analysis (EDA)
- Identify and handle missing values
- Apply appropriate statistical imputation techniques
- Detect and treat outliers using statistical methods
- Engineer at least 3 new predictive features
- Validate the cleaned dataset
- Export the final cleaned dataset

---

## Dataset

The project uses an e-commerce order dataset containing information about:

- Orders
- Customers
- Products
- Quantity
- Unit Price
- Payment Methods
- Order Status
- Shipping Information
- Cart Information
- Coupons
- Referral Sources
- Total Price

The original dataset is available in the `Initial-dataset` folder of this repository.
